# ALS-Euro redesign

Technologie:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Open Sans
- vanilla JavaScript

Zásady této verze:

- pouze původní ALS paleta: oranžová, žlutá, tmavě šedá, světlá šedá, bílá
- větší základní font a širší desktopový layout
- firemní hero ve stylu tradiční agentury, zákaznická sekce vpravo
- pod hero klasický obsahový slider
- reference 3×2
- konkrétní služby v střídavých obsahových blocích
- žádné eyebrow texty, glassmorphism, gradienty, dekorativní AI tvary ani SaaS dashboard prvky
- obsah a odkazy vycházejí z ALS-Euro a jejich současných služeb

Poznámka: obrázky a logo jsou načítány z als.cz. Pro plné zobrazení je potřeba internetové připojení.
